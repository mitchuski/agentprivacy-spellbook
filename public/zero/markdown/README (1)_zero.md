# Zero Knowledge Spellbook: Tales

This directory contains all 30 tales from the Zero Knowledge Spellbook, each as a standalone markdown file for integration into web structures.

## Structure

Each tale file follows this format:
- **Story**: Narrative featuring Soulbis (Swordsman) and Soulbae (Mage)
- **Spell Inscription**: Compressed emoji notation for trust networks
- **Technical Bridge**: Formal definitions and specifications
- **Proverb**: Wisdom connecting to sovereignty principles
- **Navigation**: Links to previous/next tales and main spellbook

## Web Integration

Each tale is designed to work as a standalone page in a "just another story" web structure:

```
/tales/
  ├── tale_01.md  → /story/tale-01
  ├── tale_02.md  → /story/tale-02
  ...
  └── tale_30.md  → /story/tale-30
```

Navigation links connect tales sequentially, with references back to the complete spellbook.

## Usage

### For Developers
- Reference specific tales when implementing ZKP features
