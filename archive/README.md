# Archived Documentation

This directory contains historical documentation that has been archived as prior/completed work.

## Structure

- **merge-docs/**: Documentation from the repository merge process (completed)
- **integration-docs/**: Implementation checklists for features that have been completed
- **fix-docs/**: Documentation of fixes that have been implemented
- **deployment-docs/**: Historical deployment guides
- **setup-docs/**: Historical setup guides
- **architecture-docs/**: Historical architecture documentation

## Purpose

These files are kept for historical reference but are no longer needed in the main documentation. They document completed processes and implementations that are now part of the codebase.
